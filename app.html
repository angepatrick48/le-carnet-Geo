Réception de profil — saisie des relevés

Cote projet drainage = ligne rouge − décrochage (ex : − 2 cm), calculée automatiquement.
Côte bleue = Côte de la borne + Lecture arrière ÷ 1000 (calcul automatique). Écart = Cote projet − Cote relevée, avec badge de conformité selon la tolérance de la couche.
Profil hors tabulation ? Ajoutez un PK intercalaire (ex : 20+625) : sa cote projet est interpolée et il rejoint les profils de la ligne rouge, dans les suggestions et sur la fiche.

Réception dalot — parties de l'ouvrage

FE = cote radier de l'ouvrage, avec pente longitudinale (fils d'eau amont → axe → aval, corps interpolés). Fond de fouille = FE − (sable + béton de propreté + radier) ; lit de sable = FE − (radier + béton de propreté) ; béton de propreté = FE − radier ; dalle = FE + hauteur de section + ép. dalle. 5 profils (amont, corps amont, axe, corps aval, aval). Sur chaque profil, les 3 points (bord gauche, axe, bord droit) ont la même cote projet (radier plat en travers) ; on relève les 3 pour contrôler la planéité.

Côte bleue = Côte borne + Lecture arrière ÷ 1000. Cote relevée = Côte bleue − Lecture ÷ 1000. Écart = Cote projet − Cote relevée.

Implantation d'une planche — lectures à réaliser

Cote projet drainage = ligne rouge − décrochage (ex : − 2 cm).
Choisissez une section proposée ou saisissez librement une section non listée (ex : 5X4X4).
Côte bleue = Côte de la borne + Lecture arrière ÷ 1000. Lecture à réaliser = (Côte bleue − Cote projet) × 1000, en mm, pour chaque position du profil.
Profil hors tabulation dans la planche ? Ajoutez un PK intercalaire (ex : 20+625) : sa cote projet est interpolée et il apparaît dans la planche générée, entre les profils de la ligne rouge.

Mon projet — informations générales

Structure de chaussée — couches & épaisseurs

De haut en bas (surface finie en haut). Nommez, ajoutez, réordonnez ou supprimez les couches. L'épaisseur sert à calculer la cote projet de chaque couche. La tolérance ± (mm) de chaque couche est utilisée en implantations et réceptions pour le calcul des écarts (badge de conformité) et la coloration des fiches (rouge si écart > +tolérance, jaune si < −tolérance). Cochez « Nivellement » pour les couches reçues à la méthode côte bleue + lecture.

Dimensions transversales

Pour chaque position : une distance à l'axe propre à chaque couche de la structure de chaussée (les couches inférieures débordent davantage). Renseignez la pente (%) de la position ; le dénivelé par rapport à l'axe (Δ) est calculé automatiquement par couche (distance de la couche × pente ÷ 100) et affiché sous chaque valeur. Cote d'une couche à cette position = cote de l'axe − cumul des épaisseurs au-dessus − Δ de la couche. Le tableau s'actualise automatiquement quand vous modifiez la structure de chaussée (couches ajoutées / renommées / supprimées). Les aires de stationnement peuvent être renommées (colonne Position) et rendus optionnels (colonne Incluse).

Marche verticale entre le bord de chaussée et l'accotement (ex. 2). Abaisse d'autant les cotes projet de l'accotement (Mode A). 0 ou vide = pas de décrochage.

Le type de route détermine le signe du dénivelé (Mode A) : en toit les deux côtés sont sous l'axe ; en dévers unique un côté est au-dessus, l'autre en dessous ; avec TPC chaque chaussée draine vers l'extérieur (côtés sous l'axe). Le Mode B (5 points) n'est pas concerné (cotes lues directement).

Manuels — Le Carnet Géo

Présentation

Le Carnet Géo enregistre les réceptions et implantations topographiques (structure de chaussée, assainissement & drainage, ouvrages hydrauliques), calcule les cotes projet, produit les fiches Excel et un récap des travaux. Il fonctionne hors‑ligne et peut se synchroniser en équipe.

1. Mon projet

  • Informations générales : nom, tronçon, PK début/fin, maître d'ouvrage, mission de contrôle, entreprise, topographe et les 3 logos — repris dans l'en‑tête des fiches.
  • Structure de chaussée : couches de haut en bas (nom, épaisseur, tolérance, nivellement). La colonne Ép. accot. permet une épaisseur d'accotement différente de la chaussée (vide = identique).
  • Dimensions transversales : distances à l'axe (par couche) et pentes des positions (Axe, Chaussée, Accotement).
  • Variation selon le PK : sections nommées. Une Agglomération modifie les dimensions sur sa plage de PK ; une Aire de stationnement (côté G/D) ajoute une position de mesure sur sa plage.
  • Ligne rouge : import des 5 points par profil (TXT/CSV/Excel/manuel).
  • Mode de calcul : A (cote à l'axe + dimensions) ou B (cotes lues directement sur la ligne rouge 5 points).

2. Espace de travail

Réceptions

  • Choisissez le type (chaussée / assainissement / ouvrage) et l'élément, puis le PK.
  • Couches au nivellement : renseignez la borne (nom, cote) et la lecture arrière (côte bleue automatique), puis la lecture par position ; la cote relevée et l'écart s'affichent. Pour la PST, la cote relevée peut être saisie directement.
  • « Profil suivant » avance automatiquement. « Exporter » génère la fiche et vide la tâche (les relevés restent dans le récap).

Implantations

  • Définissez la planche (PK début/fin), la borne et la côte bleue : l'app calcule les lectures à réaliser par profil et position. « Exporter » produit la fiche ; l'implantation est alors comptée dans le récap.

Ouvrage / Dalot

  • Dalot cadre : section (1X2X2…) et qualité (préfabriqué / construit sur site). Le module calcule les cotes des parties (fond de fouille, lit de sable, béton de propreté, dalle).

3. Fiches

En‑tête projet + logos, n° de section, positions, borne / côte bleue, cotes projet et relevées (2 décimales) avec badge de conformité, et les signataires selon le type : 3 en réception provisoire (Opérateur, Chef de brigade, Contrôleur) ou 2 en réception définitive (Chef de brigade, Contrôleur topo).

4. Récap des travaux

  • Rapport journalier : par date — type, élément, PK, profils, conformes / non conformes.
  • Synoptique : avancement par type, volet implantations, et comparatif linéaire Projet / Implanté / Réceptionné.
  • Export Excel (rapport + synoptique + implantation).

5. Synchronisation réseau (équipe)

Récap → Synchronisation réseau : connecte l'app à une base en ligne (Firebase) pour partager le récap entre tous les topographes du même projet, sans doublon. Voir le Manuel — Base Firebase.

6. Installation & hors‑ligne

  • Android : menu du navigateur → « Ajouter à l'écran d'accueil », ou installez l'application (APK).
  • iPhone : Safari → Partager → « Sur l'écran d'accueil ».
  • Après un premier chargement connecté, l'app marche hors‑ligne ; les données saisies sans réseau partent au retour de la connexion.

7. Partage avec l'équipe

Dans Mon projet : « Générer l'application avec projet intégré » crée un .html contenant votre projet (vos topographes le reçoivent rempli). « Exporter seulement le projet (.lcg) » / « Importer un projet d'équipe » échangent le projet.

Objectif

Créer une base en ligne gratuite (Firebase) pour partager le récap entre topographes. À faire une seule fois, depuis un ordinateur.

Étape 1 — Créer le projet

console.firebase.google.com → connexion Google → « Ajouter un projet » (plan Spark, gratuit).

Étape 2 — Realtime Database

Menu « Realtime Database » → « Créer une base de données » → région → mode test. L'URL de la base finit par .firebaseio.com (ce n'est PAS l'adresse de la console).

Étape 3 — Règles

Realtime Database → onglet Règles :

{ "rules": { ".read": "auth != null", ".write": "auth != null" } } → Publier.

Étape 4 — Authentification

Authentication → Commencer → onglet « Sign‑in method » → « Email/Password » → activer le 1er interrupteur « Adresse e‑mail/Mot de passe » → Enregistrer.

Étape 5 — Créer les comptes

Authentication → onglet Users → « Ajouter un utilisateur » (e‑mail + mot de passe, un par topographe).

Étape 6 — URL & clé API Web

  • URL : Realtime Database, en haut de l'onglet Données (…firebaseio.com).
  • Clé API Web : ⚙ Paramètres du projet → Général → « Clé d'API Web » (commence par AIza… ; ce n'est pas le numéro de projet).

Étape 7 — Configurer l'application

Récap → Synchronisation réseau : collez l'URL et la clé, cochez « Activer », saisissez e‑mail + mot de passe → « Se connecter ». Le statut passe au vert « connecté ».

Dépannage

  • Failed to fetch : pas de réseau, ou app en aperçu/fichier local → utilisez le lien en ligne ; vérifiez URL/clé.
  • CONFIGURATION_NOT_FOUND : Authentication non activée → étape 4.
  • PASSWORD_LOGIN_DISABLED : activez le 1er interrupteur Email/Password → étape 4.
  • EMAIL_NOT_FOUND / identifiants incorrects : créez l'utilisateur → étape 5.
  • Permission denied : publiez les règles auth != null et connectez‑vous.

Sécurité : seuls les comptes créés dans Authentication accèdent à la base. L'URL et la clé ne sont pas des secrets ; c'est le mot de passe qui protège.
